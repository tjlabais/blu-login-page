Stylize WordPress wp-admin login page 

== Description ==

Install the template and customize the wp-login by editing the login-styles.css

Features:
* custom-logo.png in /wp-content/uploads
* removed registration link
* modern form look
* customizable branding colors
* clean message box

== Installation ==

1. Upload the plugin zip file.
2. Activate the plugin through the 'Plugins' menu in WordPress.
